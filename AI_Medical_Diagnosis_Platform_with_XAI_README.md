# AI Medical Diagnosis Platform with Explainable AI (XAI)

An intelligent healthcare application that leverages Artificial
Intelligence (AI), Machine Learning (ML), and Explainable AI (XAI) to
assist in disease prediction and medical image analysis. The platform
helps clinicians and researchers understand model decisions through
transparent visual explanations.

## Key Features

-   AI-based medical diagnosis support
-   Chest X-ray pneumonia detection
-   Explainable AI (Grad-CAM/heatmap) visualizations
-   Patient record and history management
-   Automated PDF report generation
-   Secure image upload and processing
-   Responsive web dashboard

## Technology Stack

-   Python
-   Flask
-   TensorFlow / Keras
-   OpenCV
-   HTML, CSS, JavaScript
-   SQLite
-   ReportLab

## Installation

1.  Clone the repository.
2.  Install dependencies using `pip install -r requirements.txt`.
3.  Launch the application with `python app.py`.
