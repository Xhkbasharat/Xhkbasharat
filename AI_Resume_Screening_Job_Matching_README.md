# AI Resume Screening & Job Matching Portal

An intelligent web application that automates resume screening and
matches candidates with relevant job roles using Artificial Intelligence
and Natural Language Processing (NLP).

## Features

-   Upload resumes in PDF or DOCX format
-   Automatic skill extraction and keyword analysis
-   Resume ranking based on job descriptions
-   AI-powered job matching and recommendations
-   Candidate scoring dashboard
-   Recruiter-friendly interface
-   Secure data handling

## Tech Stack

-   Python
-   Flask
-   Scikit-learn
-   spaCy / NLP
-   Pandas
-   HTML, CSS, JavaScript
-   SQLite

## Installation

1.  Clone the repository.
2.  Install dependencies: `pip install -r requirements.txt`
3.  Start the application: `python app.py`
