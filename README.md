# Job Portal & Recruitment Management System

A full-stack web-based recruitment platform developed using **Python, Flask, SQLite, HTML, CSS, and JavaScript**. The system connects job seekers and employers and provides separate functionality for candidates, employers, and administrators.

## Features

- User registration and secure authentication
- Candidate and employer profiles
- Job posting and management
- Job search and filtering
- Resume upload
- Online job applications
- Candidate dashboard
- Employer dashboard
- Administrator dashboard
- CRUD operations for jobs, users, and applications
- SQLite database integration
- Responsive and user-friendly interface

## Technologies Used

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite
- **Development:** CRUD, Authentication, Web Application Development

## Project Objective

The objective of this project is to provide a centralized platform that simplifies the recruitment process by allowing employers to publish job opportunities and manage applications while enabling job seekers to search and apply for suitable positions.

## Key Learning

This project provided practical experience in **full-stack web development, Flask application development, database management, user authentication, CRUD operations, and responsive UI development**.
